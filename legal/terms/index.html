1. Description du service

Mahdi Academy est une application mobile de révision pour le Baccalauréat général (séries A, ABI, C, D), proposant une bibliothèque de questions d'examens passés, réponses modèles, explications, et un mode de révision quotidien (Mode Séries). Le service est disponible sur l'application mobile (Android et iOS) ; le contenu n'est pas accessible depuis un navigateur web.
